

Interfaceamento de Exames Laboratoriais

Sobre o projeto

Este projeto simula a comunicação entre um equipamento de laboratório e um sistema de gestão de exames.

O sistema permite cadastrar amostras, receber resultados enviados pelo equipamento e acompanhar o processo até a liberação do exame.
Exemplo de funcionamento
1. Cadastro de uma amostra para o exame de Creatinina.
2. Recebimento do resultado enviado pelo equipamento.
3. Atualização do status para EXECUTADO.
4. Liberação do resultado.
   Tecnologias utilizadas
- Java
- Spring Boot
- Spring Data JPA
- MySQL
- Maven
- Postman
  Exemplo de resultado
- Exame: Creatinina
- Resultado: 0,93 mg/dL
- Status: LIBERADO
  Objetivo
  Praticar o desenvolvimento de APIs REST com Java e simular uma situação do cotidiano de um laboratório de análises clínicas.
